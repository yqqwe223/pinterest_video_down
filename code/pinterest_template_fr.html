📥 Guide d’utilisation détaillé (3 étapes simples)

Étape 1 : Copiez le lien du Pin Pinterest

  1. Ouvrez le site officiel de Pinterest ou l’application
  2. Trouvez le Pin public que vous souhaitez télécharger (vidéo ou image)
  3. Cliquez sur l’icône « Partager » en bas à droite → choisissez « Copier le lien »
    Exemple de lien :
    https://www.pinterest.com/pin/123456789012345678/
    ou lien court :
    https://pin.it/Abc123X

💡 Important : Seuls les Pins publics peuvent être téléchargés. Les Pins appartenant à des tableaux secrets ou restreints ne peuvent pas être analysés.

Étape 2 : Collez le lien et analysez

  1. Revenez sur cette page du téléchargeur
  2. Collez le lien dans la zone de saisie en haut (la fonction de téléchargement sera intégrée ici ultérieurement)
  3. Cliquez sur le bouton 【Analyser le contenu】

Le système effectuera en quelques secondes les actions suivantes :
• Identifiera automatiquement s’il s’agit d’une vidéo ou d’une image
• Récupérera le lien direct vers le média original en haute qualité
• Affichera un aperçu et les options de téléchargement

Étape 3 : Téléchargez le contenu en haute qualité

  • Pins vidéo : Cliquez sur « Télécharger MP4 » pour enregistrer la vidéo HD
  • Pins image : Cliquez sur « Télécharger l’image originale » pour obtenir le fichier JPG/PNG
  • Le fichier sera automatiquement enregistré dans le dossier « Téléchargements » de votre appareil

❓ Questions fréquentes (FAQ)

Q : Pourquoi le message « Impossible de récupérer le contenu » s’affiche-t-il ?
Causes possibles : le Pin est privé, le lien est invalide, le contenu a été supprimé, ou Pinterest a temporairement restreint l’accès public.
Q : Peut-on télécharger un tableau entier (Board) ?
La version actuelle ne prend en charge que le téléchargement d’un seul Pin à la fois. Une fonction de téléchargement groupé est en cours de développement.
Q : L’image téléchargée est-elle en résolution d’origine ?
Oui ! Nous fournissons l’image dans la plus haute résolution disponible sur Pinterest, pas une vignette.
Q : Comment copier le lien sur mobile ?
Dans l’application Pinterest, appuyez sur « Partager » → « Copier le lien ». Sur certains appareils Android, il est préférable d’ouvrir le Pin dans Chrome avant de copier le lien.
Q : Prend-il en charge les contenus publicitaires de Pinterest ?
Non. Les Pins publicitaires sont généralement soumis à des restrictions supplémentaires et leurs droits d’auteur sont complexes. Cet outil les ignore automatiquement.
