📥 Panduan penggunaan detail(selesai dalam 3 langkah)

Langkah 1: Salin tautan Pinterest Pin

  1. Buka situs web resmi Pinterest atau aplikasi
  2. Temukan Pin publik (video/gambar) yang ingin diunduh
  3. Ketuk ikon "Bagikan" di kanan bawah → pilih "Salin tautan"
    Contoh tautan:
    https://www.pinterest.com/pin/123456789012345678/
    Tautan pendek:
    https://pin.it/Abc123X

💡 Penting: Hanya Pin publik yang dapat diunduh. Papan rahasia atau konten terbatas tidak dapat diurai.

Langkah 2: Tempel tautan dan uraikan

  1. Kembali ke halaman pengunduh
  2. Tempelkan tautan yang disalin ke kotak input atas (nanti akan terintegrasi fungsi unduhan Anda)
  3. Klik tombol 【Uraikan konten】

Dalam hitungan detik sistem akan:
• otomatis mengenali video atau gambar
• mendapatkan tautan langsung media HD asli
• menampilkan pratinjau dan opsi unduhan

Langkah 3: Unduh konten HD

  • Pin video: klik “Unduh MP4” untuk menyimpan video HD
  • Pin gambar: klik “Unduh asli” untuk mendapatkan file JPG/PNG
  • File akan otomatis tersimpan di folder "Unduhan" perangkat

📌 Saran penggunaan:

  • Mengumpulkan inspirasi desain? → unduh asli untuk membangun perpustakaan lokal
  • Menyimpan video tutorial? → unduh MP4 untuk ditonton offline
  • Merencanakan konten? → simpan kasus referensi (saat ini dukungan per Pin tunggal)

⚙️ Keterangan teknis(untuk pengembang)

  • Menguraikan JSON-LD dan skrip tertanam dari halaman Pinterest publik untuk mengekstrak URL media asli.
  • Video dalam format MP4 standar, gambar JPG/PNG asli, tanpa watermark Pinterest atau kompresi thumbnail.
  • Pemrosesan otomatis pengalihan tautan pendek(pin.it) memastikan kompatibilitas semua format tautan.
  • Semua permintaan diproses melalui saluran aman, tidak mengirim informasi identitas pengguna ke Pinterest.
  • Tautan langsung media biasanya berlaku beberapa jam; segera unduh.

❓ Pertanyaan umum(FAQ)

Q: Mengapa muncul "Tidak dapat mendapatkan konten"?
Kemungkinan: Pin pribadi, tautan tidak valid, konten telah dihapus, atau Pinterest untuk sementara membatasi akses publik.
Q: Dapatkah mengunduh seluruh papan(board)?
Versi saat ini hanya mendukung unduhan per Pin. Fitur batch sedang direncanakan.
Q: Apakah gambar yang diunduh dalam resolusi asli?
Ya! Kami menyediakan gambar asli dengan resolusi tertinggi yang tersimpan di Pinterest, bukan thumbnail.
Q: Bagaimana menyalin tautan di ponsel?
Di aplikasi Pinterest ketuk "Bagikan" → "Salin tautan". Beberapa model Android disarankan membuka Pin di Chrome terlebih dahulu.
Q: Apakah mendukung konten iklan Pinterest?
Tidak. Pin iklan biasanya memiliki pembatasan tambahan dan hak cipta yang rumit; alat ini akan melewatkannya secara otomatis.
