📥 상세 사용 튜토리얼(3단계로 끝내기)

1단계: Pinterest Pin 링크 복사

  1. Pinterest 공식 사이트 또는 앱 열기
  2. 다운로드하고 싶은 공개 Pin(동영상/이미지) 찾기
  3. 우측 하단 “공유” 아이콘 → “링크 복사” 선택
    링크 예시:
    https://www.pinterest.com/pin/123456789012345678/
    짧은 링크:
    https://pin.it/Abc123X

💡 중요: 공개 Pin만 다운로드 가능합니다. 시크릿 보드나 제한된 콘텐츠는 분석할 수 없습니다.

2단계: 링크 붙여넣기 및 분석

  1. 다운로더 페이지로 돌아가기
  2. 복사한 링크를 상단 입력창에 붙여넣기(향후 다운로드 기능 통합 예정)
  3. 【콘텐츠 분석】 버튼 클릭

수 초 내 시스템이:
• 동영상/이미지 자동 인식
• 원본 HD 미디어 직링크 획득
• 미리보기 및 다운로드 옵션 표시

3단계: 고화질 콘텐츠 다운로드

  • 동영상 Pin: “MP4 다운로드” 클릭하여 HD 영상 저장
  • 이미지 Pin: “원본 다운로드” 클릭하여 JPG/PNG 파일 받기
  • 파일은 기기의 “다운로드” 폴더에 자동 저장됩니다

📌 활용 추천:

  • 디자인 영감 모으기? → 원본 다운로드로 로컬 소재 라이브러리 구축
  • 튜토리얼 영상 저장? → MP4 다운로드로 오프라인 시청
  • 콘텐츠 기획? → 참고 케이스 보관(현재 단일 Pin 지원)

⚙️ 기술 설명(개발자 참고)

  • Pinterest 공개 페이지의 JSON-LD와 임베디드 스크립트를 파싱하여 원본 미디어 URL 추출.
  • 동영상은 표준 MP4 형식, 이미지는 원본 JPG/PNG, Pinterest 워터마크나 썸네일 압축 없음.
  • 짧은 링크(pin.it) 리다이렉트 자동 처리, 모든 링크 형식 호환.
  • 모든 요청은 안전한 채널을 통해 처리되며 Pinterest에 사용자 신원 정보를 전송하지 않음.
  • 미디어 직링크는 보통 몇 시간 후 만료; 신속히 다운로드하세요.

⚠️ 이용약관 및 저작권 정책

  1. 공개 콘텐츠만: 시크릿 보드, 제한된 Pin, 광고 콘텐츠 다운로드를 시도하지 마십시오.
  2. 지적재산권 존중: Pinterest 콘텐츠는 대부분 제3자 창작물입니다. 상업적 재배포, 판매, 침해 용도로 사용 금지.

❓ 자주 묻는 질문(FAQ)

Q: "콘텐츠를 가져올 수 없습니다"라고 뜨는 이유는?
가능한 원인: Pin이 비공개, 링크 무효, 콘텐츠 삭제됨, 혹은 Pinterest가 일시적으로 공개 접근을 제한함.
Q: 보드 전체를 다운로드할 수 있나요?
현재 버전은 단일 Pin 다운로드만 지원합니다. 일괄 다운로드 기능은 계획 중입니다.
Q: 다운로드한 이미지는 원본 해상도인가요?
네! Pinterest에 저장된 최고 해상도 원본을 제공하며, 썸네일이 아닙니다.
Q: 모바일에서 링크를 복사하려면?
Pinterest 앱에서 "공유" → "링크 복사". 일부 Android 기기에서는 Chrome로 Pin을 연 뒤 복사하는 것을 권장합니다.
Q: Pinterest 광고 콘텐츠를 지원하나요?
지원하지 않습니다. 광고 Pin은 추가 제한과 복잡한 저작권이 있어 본 도구가 자동으로 건너뜁니다.
