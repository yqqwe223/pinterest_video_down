📥 Guia de utilização detalhado (3 passos simples)

Passo 1: Copie o link do Pin do Pinterest

  1. Abra o site oficial do Pinterest ou a aplicação
  2. Encontre o Pin público que pretende descarregar (vídeo ou imagem)
  3. Clique no ícone “Partilhar” no canto inferior direito → selecione “Copiar link”
    Exemplo de link:
    https://www.pinterest.com/pin/123456789012345678/
    ou link curto:
    https://pin.it/Abc123X

💡 Importante: Apenas Pins públicos podem ser descarregados. Pins de quadros secretos ou conteúdo restrito não podem ser analisados.

Passo 2: Cole o link e analise

  1. Volte para esta página do descarregador
  2. Coloque o link copiado na caixa de entrada no topo (a funcionalidade de descarregamento será integrada aqui futuramente)
  3. Clique no botão 【Analisar conteúdo】

O sistema irá, em poucos segundos:
• Identificar automaticamente se é vídeo ou imagem
• Obter o link direto para o ficheiro multimédia original em alta qualidade
• Mostrar uma pré-visualização e as opções de descarregamento

Passo 3: Descarregue o conteúdo em alta qualidade

  • Pins de vídeo: clique em “Descarregar MP4” para guardar o vídeo em alta definição
  • Pins de imagem: clique em “Descarregar imagem original” para obter o ficheiro JPG/PNG
  • O ficheiro será guardado automaticamente na pasta “Transferências” do seu dispositivo

  • Analisa o JSON-LD e scripts incorporados das páginas públicas do Pinterest para extrair o URL original do conteúdo multimédia.
  • Os vídeos são fornecidos em formato MP4 padrão, as imagens em JPG/PNG original, sem marca d’água do Pinterest nem compressão de miniatura.
  • Processa automaticamente redirecionamentos de links curtos (pin.it) para garantir compatibilidade com todos os formatos de link.

❓ Perguntas frequentes (FAQ)

P: Por que surge a mensagem “Não foi possível obter o conteúdo”?
Possíveis causas: o Pin é privado, o link é inválido, o conteúdo foi eliminado ou o Pinterest restringiu temporariamente o acesso público.
P: É possível descarregar um quadro inteiro (Board)?
A versão atual suporta apenas o descarregamento de um único Pin de cada vez. A funcionalidade de descarregamento em massa está em desenvolvimento.
P: A imagem descarregada está na resolução original?
Sim! Fornecemos a imagem com a resolução máxima disponível no Pinterest, não uma miniatura.
P: Como copiar o link no telemóvel?
Na aplicação Pinterest, toque em “Partilhar” → “Copiar link”. Em alguns dispositivos Android, recomenda-se abrir o Pin no Chrome antes de copiar o link.
P: Suporta conteúdo publicitário do Pinterest?
Não. Os Pins publicitários estão geralmente sujeitos a restrições adicionais e os direitos de autor são complexos. Esta ferramenta ignora automaticamente esse tipo de conteúdo.
