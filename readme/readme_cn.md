## ✨ 功能特性

- 🔗 **链接智能解析**：粘贴 Pinterest 公开页面链接，自动识别并提取媒体资源
- 🎬 **多格式支持**：支持 MP4 视频、JPG/PNG 图片等多种常见格式
- 📱 **响应式设计**：适配桌面端与移动端，操作简洁流畅
- ⚡ **快速处理**：前端解析为主，响应迅速，无需等待长时间排队
- 🔒 **隐私保护**：不存储用户提交的链接与下载内容，即开即用
- 🌍 **多语言友好**：界面支持中文，方便国内用户使用

## 🚀 使用指南

1. 打开 Pinterest App 或网页，找到您希望保存的**公开内容**
2. 复制该内容的页面链接（例如：`https://www.pinterest.com/pin/xxxxxx/`）
3. 访问本工具页面，将链接粘贴至输入框
4. 点击「解析」按钮，等待系统提取可用资源
5. 选择所需清晰度/格式，右键「另存为」即可保存至本地

> 💡 温馨提示：请确保您下载的内容仅用于**个人学习、研究或已获得授权的场景**，尊重原创作者权益。

## ❓ 常见问题

**Q：为什么有些链接无法解析？**  
A：可能原因包括：① 内容为私密/需登录可见；② Pinterest 页面结构临时调整；③ 网络请求被拦截。建议尝试刷新页面或更换网络环境。

**Q：下载的视频有水印吗？**  
A：本工具仅提取平台已提供的原始资源链接，是否包含水印取决于 Pinterest 官方输出，本工具不添加、不移除任何水印。

**Q：支持批量下载吗？**  
A：当前版本聚焦单链接解析，以保障稳定性与合规性。批量需求请评估是否符合平台规则，并谨慎使用。
