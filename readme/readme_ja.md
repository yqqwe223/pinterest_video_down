# Pinterest メディアダウンローダー (Pinterest Media Downloader)

> 🔍 Pinterest 公開コンテンツのメタデータ解析をサポートする学習・研究用ツール

🌐 オンライン体験：[https://twittervideodownloaderx.com/pinterest_downloader_ja](https://twittervideodownloaderx.com/pinterest_downloader_ja)

---

## 📋 プロジェクト概要

本プロジェクトは、フロントエンド技術の学習と研究を目的とした軽量な解析ツールです。Pinterest の公開ページから提供される OEmbed 接口や構造化データ（Schema.org / Open Graph）を活用し、動画・画像などのメディアリソース情報を抽出するサポート機能を提供します。

> 🎯 推奨ユースケース：
> - 個人での学習資料・アイデア収集
> - フロントエンド開発・データ抽出技術の研究
> - マルチメディアメタデータの解析学習
> - 著作権者から許可を得たコンテンツのアーカイブ支援

⚠️ **重要**：本ツールは「公開情報のみ」を対象としており、ログイン認証・有料コンテンツ・非公開ピンの解析には対応していません。

---

## ✨ 主な機能

- 🔗 **リンク自動認識**：Pinterest 公開ピンページの標準 URL／ショートリンク／モバイルリンクを自動判別
- 🎬 **多フォーマット対応**：MP4 動画、WebM アニメーション、JPG/PNG 静止画などのリソース情報抽出
- 📐 **解像度情報表示**：利用可能な解像度・ファイル形式を一覧表示、用途に合わせて選択可能
- 📱 **レスポンシブデザイン**：PC／タブレット／スマートフォン、あらゆる端末で快適に操作可能
- ⚡ **フロントエンド優先設計**：主要な解析処理をブラウザ側で実行、サーバー負荷を軽減し高速レスポンスを実現
- 🔐 **プライバシー配慮**：送信リンクの記録・解析結果の保存・個人データの収集を一切行いません

---

## 🚀 使い方（クイックスタート）

1. Pinterest アプリまたはウェブサイトで、保存したい**公開コンテンツ**を開く
2. アドレスバーからページの URL をコピー（例：`https://www.pinterest.com/pin/1234567890/`）
3. 本ツールの入力欄にリンクを貼り付け、「解析」ボタンをクリック
4. システムが公開メタデータを抽出し、利用可能なリソース情報を表示
5. 目的の形式・解像度を選択し、右クリック→「名前を付けて保存」でローカルに保存

> 💡 利用のヒント：
> - 対象コンテンツが「公開設定」であることを必ずご確認ください
> - 解析に失敗した場合は、ページを更新するかネットワーク環境を確認してください
> - 開発学習には、ブラウザの開発者ツール（F12 → Network → Fetch/XHR）の併用を推奨します

## 🛠 技術実装メモ（開発者向け）

> 一般ユーザーの方は本セクションをスキップしていただいて結構です

### アーキテクチャ概要
```
ユーザーブラウザ → フロントエンド解析モジュール → Pinterest 公開接口 / OEmbed → 構造化データ抽出 → 結果表示
```

### 主要技術ポイント
- `fetch` API + 適切な CORS プロキシ設定による公開ページメタデータ取得
- `<script type="application/ld+json">` 内の Schema.org 構造化データのパース
- Open Graph タグ（`og:video` / `og:image` / `og:title` 等）を活用したリソース補完
- 正規表現 + DOM 解析の二重検証によるリンク認識の堅牢性向上

### ローカルデプロイ手順（参考）
```bash
# 1. リポジトリのクローン（例）
git clone https://github.com/yourname/pinterest-downloader-ja.git

# 2. 静的ファイルホスティング（HTTPS 必須推奨）
#    - Vercel / Netlify / Cloudflare Pages（手軽で推奨）
#    - Nginx + Let's Encrypt 証明書（自建サーバー）

# 3. セキュリティヘッダー設定例（Nginx）
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline';";
add_header X-Content-Type-Options "nosniff";
add_header Referrer-Policy "strict-origin-when-cross-origin";
```

> 🔐 本番環境での注意事項：
> - 必ず HTTPS を有効化し、中間者攻撃を防止してください
> - 過度なリクエストを制限するレートリミット設定を推奨します
> - 解析ロジックの過度な公開は、悪用リスクを高めるため控えてください

## ❓ よくある質問（FAQ）

**Q：「コンテンツを取得できません」と表示されるのですが？**  
A：考えられる原因：① リンク先が非公開・削除済みコンテンツ ② Pinterest 側のページ構造一時的変更 ③ ネットワーク制限・CORS 問題。対処法：公開設定を確認 → 別ネットワークで試行 → 時間をおいて再試行。

**Q：ダウンロードした動画に透かしが入っていますが？**  
A：本ツールは Pinterest 公式が提供しているオリジナルリソースリンクをそのまま返す仕様です。透かしの有無はアップロード時の設定に依存し、本ツールによる追加・削除処理は一切行っておりません。

**Q：アルバムやボードの一括解析には対応していますか？**  
A：現バージョンは単一ピンの解析に特化しており、安定性とコンプライアンスを優先しています。一括取得のご要望については、まず Pinterest 社の「Developer Policy」に準拠しているかをご自身でご確認ください。

**Q：利用履歴や個人情報は収集されますか？**  
A：いいえ。本プロジェクトは純粋な静的フロントエンドページであり、バックエンドログ・解析スクリプト・Cookie トラッキングを一切含んでおりません。すべての処理はお客様のブラウザ内で完結します。
