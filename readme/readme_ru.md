# Pinterest Media Analyzer (Анализатор медиаконтента Pinterest)

> 🔍 Легковесный фронтенд-инструмент для образовательных и исследовательских целей, поддерживающий извлечение метаданных из общедоступного контента Pinterest

🌐 Онлайн-демо: [https://twittervideodownloaderx.com/pinterest_downloader_ru](https://twittervideodownloaderx.com/pinterest_downloader_ru)

---

## 📋 Описание проекта

Данный проект разработан в образовательных и исследовательских целях. Это легковесная фронтенд-утилита, предназначенная для помощи разработчикам и студентам в изучении методов извлечения структурированных метаданных (таких как Schema.org и Open Graph) из общедоступных страниц Pinterest с использованием стандартных веб-API, таких как OEmbed.

> 🎯 Рекомендуемые сценарии использования:
> - Организация личных учебных материалов и сбор идей
> - Практика фронтенд-разработки и исследование методов извлечения веб-данных
> - Изучение структур мультимедийных метаданных
> - Архивирование контента при наличии явного разрешения правообладателей

⚠️ **Важное уведомление**: Этот инструмент работает исключительно с **общедоступным контентом**. Он не предназначен и не имеет возможности для доступа к контенту Pinterest, требующему входа в систему, являющемуся платным или настроенному как приватный.

---

## ✨ Основные возможности

- 🔗 **Интеллектуальное распознавание ссылок**: Автоматически определяет стандартные URL пинов Pinterest, короткие ссылки и мобильные форматы
- 🎬 **Поддержка множества форматов**: Извлекает метаданные для видео MP4, анимаций WebM, изображений JPG/PNG и других распространённых медиаформатов
- 📐 **Отображение информации о разрешении**: Показывает доступные варианты разрешения и форматы файлов для осознанного выбора
- 📱 **Полностью адаптивный дизайн**: Оптимизированный пользовательский опыт на настольных компьютерах, планшетах и мобильных устройствах
- ⚡ **Архитектура с приоритетом клиентской части**: Основная логика анализа выполняется в браузере, уменьшая зависимость от сервера и повышая скорость отклика
- 🔐 **Дизайн с уважением к конфиденциальности**: Не регистрирует отправленные URL, не хранит результаты анализа и не собирает личные данные пользователей

## 🚀 Краткое руководство по использованию

1. Откройте приложение или веб-сайт Pinterest и найдите **общедоступный контент**, который вы хотите использовать
2. Скопируйте URL страницы из адресной строки браузера (пример: `https://www.pinterest.com/pin/1234567890/`)
3. Вставьте ссылку в поле ввода данного инструмента и нажмите кнопку "Анализировать"
4. Система извлечёт общедоступные метаданные и отобразит информацию о доступных ресурсах
5. Выберите предпочтительный формат/разрешение, затем щёлкните правой кнопкой мыши по ссылке и выберите "Сохранить ссылку как..." для локального скачивания

> 💡 Советы по использованию:
> - Всегда проверяйте, что целевой контент имеет настройку видимости "Публичный"
> - Если анализ не удался, попробуйте обновить страницу или проверить подключение к сети
> - В учебных целях рекомендуется использовать Инструменты разработчика браузера (F12 → Network → Fetch/XHR) совместно с этим инструментом

## 🛠 Технические заметки по реализации (Для разработчиков)

> Обычные пользователи могут пропустить этот раздел

### Обзор архитектуры
```
Браузер пользователя → Клиентский модуль анализа → Публичные эндпоинты Pinterest / OEmbed → Извлечение структурированных данных → Отображение результатов
```

### Ключевые технические подходы
- Использует API `fetch` с соответствующей настройкой CORS-прокси для получения метаданных публичных страниц
- Анализирует структурированные данные Schema.org из тегов `<script type="application/ld+json">`
- Использует метаданные Open Graph (`og:video`, `og:image`, `og:title` и др.) для обнаружения ресурсов
- Реализует двойную валидацию через регулярные выражения + парсинг DOM для надёжного распознавания ссылок

### Руководство по самостоятельному хостингу (Справочно)
```bash
# 1. Клонировать репозиторий (пример)
git clone https://github.com/yourname/pinterest-downloader-ru.git

# 2. Разместить статические файлы (настоятельно рекомендуется HTTPS)
#    - Vercel / Netlify / Cloudflare Pages (простая настройка, рекомендуется)
#    - Nginx + сертификат Let's Encrypt (вариант самостоятельного хостинга)

# 3. Пример настройки заголовков безопасности (Nginx)
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline';";
add_header X-Content-Type-Options "nosniff";
add_header Referrer-Policy "strict-origin-when-cross-origin";
add_header X-Frame-Options "DENY";
```

> 🔐 Лучшие практики для развёртывания в продакшене:
> - Всегда включайте HTTPS для предотвращения атак типа "человек посередине"
> - Реализуйте ограничение частоты запросов (rate limiting) для предотвращения злоупотреблений
> - Избегайте раскрытия чувствительной логики анализа, которая может быть использована во вред
> - Регулярно проверяйте и обновляйте зависимости для применения исправлений безопасности

## ❓ Часто задаваемые вопросы (FAQ)

**В: Почему появляется сообщение "Не удалось получить контент"?**  
О: Возможные причины: ① Ссылка указывает на приватный/удалённый контент ② Pinterest временно изменил структуру страницы ③ Ограничения сети или проблемы с CORS. Решение: Проверьте публичный статус → Попробуйте в другой сети → Подождите и повторите попытку.

**В: Содержит ли скачанное видео водяные знаки?**  
О: Этот инструмент возвращает оригинальные URL ресурсов, предоставляемые официальной инфраструктурой Pinterest. Наличие водяных знаков полностью зависит от настроек пользователя, загрузившего контент. Этот инструмент не добавляет, не удаляет и не изменяет никакие водяные знаки или встроенные отметки.

**В: Поддерживается ли пакетная обработка для альбомов или досок?**  
О: Текущая версия ориентирована на анализ отдельных пинов для обеспечения стабильности и соблюдения нормативных требований. Для пакетных операций, пожалуйста, сначала убедитесь, что ваш сценарий использования соответствует [Политике для разработчиков](https://developers.pinterest.com/docs/api/policy/) Pinterest в отношении ограничений частоты и использования данных.

**В: Собирает ли этот инструмент мои данные об использовании или личную информацию?**  
О: Нет. Это чисто статический фронтенд-проект без ведения журналов на бэкенде, аналитических скриптов или отслеживания на основе куки. Вся обработка происходит локально в рамках вашей браузерной сессии.
