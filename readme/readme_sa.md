## 📋 نظرة عامة على المشروع

تم تطوير هذا المشروع لأغراض تعليمية وبحثية تقنية. وهي أداة واجهة أمامية خفيفة مصممة لمساعدة المطورين والطلاب على فهم كيفية استخراج البيانات الوصفية المهيكلة (مثل علامات Schema.org وOpen Graph) من صفحات بينتيريست المتاحة للعامة، باستخدام واجهات برمجة تطبيقات الويب القياسية مثل OEmbed.

> 🎯 حالات الاستخدام الموصى بها:
> - تنظيم مواد الدراسة الشخصية وجمع الأفكار
> - ممارسة تطوير الواجهات الأمامية والبحث في استخراج بيانات الويب
> - التعلم حول هياكل البيانات الوصفية للوسائط المتعددة
> - أرشفة المحتوى بموافقة صريحة من أصحاب حقوق النشر

⚠️ **تنويه مهم**: تعمل هذه الأداة حصريًا مع **المحتوى المتاح للعامة**. لا تهدف ولا تمكّن من الوصول إلى محتوى بينتيريست الذي يتطلب تسجيل الدخول، أو المحتوى المدفوع، أو المحتوى المُعد كخاص.

## ✨ الميزات الرئيسية

- 🔗 **التعرف الذكي على الروابط**: يكتشف تلقائيًا عناوين URL القياسية لـ Pins بينتيريست، والروابط المختصرة، والتنسيقات المحمولة
- 🎬 **دعم تنسيقات متعددة**: يستخرج البيانات الوصفية لفيديوهات MP4، ورسوم متحركة WebM، وصور JPG/PNG، وغيرها من تنسيقات الوسائط الشائعة
- 📐 **عرض معلومات الدقة**: يُظهر خيارات الدقة وتنسيقات الملفات المتاحة للاختيار الواعي
- 📱 **تصميم متجاوب بالكامل**: تجربة مستخدم محسّنة لأجهزة سطح المكتب والأجهزة اللوحية والهواتف المحمولة
- ⚡ **هندسة تعتمد على جانب العميل أولاً**: يتم تنفيذ منطق التحليل الرئيسي في المتصفح، مما يقلل من اعتمادية الخادم ويحسن سرعة الاستجابة
- 🔐 **تصميم يحترم الخصوصية**: لا يسجل عناوين URL المرسلة، ولا يخزن نتائج التحليل، ولا يجمع أي بيانات شخصية للمستخدمين

## 🚀 دليل البدء السريع

<ol dir="rtl">
  <li>افتح تطبيق أو موقع بينتيريست وحدد **المحتوى العام** الذي ترغب في الرجوع إليه</li>
  <li>انسخ عنوان URL للصفحة من شريط عناوين المتصفح (مثال: <code>https://www.pinterest.com/pin/1234567890/</code>)</li>
  <li>ألصق الرابط في حقل الإدخال بهذه الأداة وانقر على زر "تحليل"</li>

  <li>حدد التنسيق/الدقة المفضل، ثم انقر بزر الماوس الأيمن على الرابط واختر "حفظ الرابط باسم..." للتنزيل محليًا</li>
</ol>

> 💡 نصائح الاستخدام:
> - تأكد دائمًا من أن المحتوى المستهدف مضبوط على وضوح الرؤية "عام"
> - إذا فشل التحليل، حاول تحديث الصفحة أو التحقق من اتصال الشبكة
> - لأغراض التعلم، يُنظر في استخدام أدوات المطور في المتصفح (F12 → Network → Fetch/XHR) جنبًا إلى جنب مع هذه الأداة

## 🛠 ملاحظات التنفيذ التقني (للمطورين)

> يمكن للمستخدمين العاديين تخطي هذا القسم

### نظرة عامة على الهندسة
```
متصفح المستخدم → وحدة التحليل من جانب العميل → نقاط نهاية بينتيريست العامة / OEmbed → استخراج البيانات المهيكلة → عرض النتائج
```

### النهج التقنية الرئيسية
- يستخدم واجهة برمجة التطبيقات `fetch` مع تكوين وكيل CORS مناسب لاسترداد البيانات الوصفية من الصفحات العامة
- يحلل بيانات Schema.org المهيكلة من علامات `<script type="application/ld+json">`
> يستفيد من بيانات تعريف Open Graph (`og:video`، `og:image`، `og:title`، إلخ) لاكتشاف الموارد
- يطبق التحقق المزدوج عبر أنماط التعبيرات النمطية + تحليل DOM للتعرف القوي على الروابط

### دليل الاستضافة الذاتية (مرجع)
```bash
# 1. استنساخ المستودع (مثال)
git clone https://github.com/yourname/pinterest-downloader-ar.git

# 2. نشر الملفات الثابتة (يُوصى بشدة باستخدام HTTPS)
#    - Vercel / Netlify / Cloudflare Pages (إعداد سهل، موصى به)
#    - Nginx + شهادة Let's Encrypt (خيار الاستضافة الذاتية)

# 3. مثال تكوين رؤوس الأمان (Nginx)
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline';";
add_header X-Content-Type-Options "nosniff";
add_header Referrer-Policy "strict-origin-when-cross-origin";
add_header X-Frame-Options "DENY";
```

> 🔐 أفضل الممارسات للنشر في بيئة الإنتاج:
> - مكن دائمًا من HTTPS لمنع هجمات الرجل في المنتصف
> - نفذ تحديد معدل الطلبات (rate limiting) لمنع إساءة الاستخدام والطلبات المفرطة
> - تجنب تعريض منطق التحليل الحساس الذي قد يُساء استخدامه
> - راجع وحدّث التبعيات بانتظام لتطبيق تصحيحات الأمان

**س: هل يحتوي الفيديو الذي تم تنزيله على علامات مائية؟**

**س: هل تدعم المعالجة المجمعة للألبومات أو اللوحات؟**  
ج: يركز الإصدار الحالي على تحليل الـ Pins الفردية لإعطاء الأولوية للاستقرار والامتثال التنظيمي. للعمليات المجمعة، يُرجى أولاً التأكد من أن حالة الاستخدام الخاصة بك تتماشى مع [سياسة المطورين](https://developers.pinterest.com/docs/api/policy/) لـ بينتيريست فيما يتعلق بحدود المعدل واستخدام البيانات.

**س: هل تجمع هذه الأداة بيانات الاستخدام الخاصة بي أو المعلومات الشخصية؟**
