## 📋 ข้อมูลเบื้องต้นของโปรเจกต์

โปรเจกต์นี้พัฒนาขึ้นเพื่อวัตถุประสงค์ทางการศึกษาและวิจัยทางเทคนิค เป็นเครื่องมือ фронтเอนด์น้ำหนักเบาที่ช่วยสนับสนุนการดึงข้อมูลเมตาของสื่อต่างๆ เช่น วิดีโอและรูปภาพ จากหน้าเพจสาธารณะของ Pinterest โดยใช้ข้อมูลจาก OEmbed Interface และ Structured Data (Schema.org / Open Graph) ที่แพลตฟอร์มเปิดเผย

> 🎯 กรณีการใช้งานที่แนะนำ:
> - การจัดระเบียบวัสดุการเรียนรู้ส่วนตัวและการรวบรวมไอเดีย
> - การวิจัยและพัฒนาเทคนิคการดึงข้อมูลเว็บ (Frontend Development)
> - การศึกษาโครงสร้างข้อมูลเมตาของมัลติมีเดีย
> - การสนับสนุนการเก็บถาวรเนื้อหาที่ได้รับอนุญาตจากเจ้าของลิขสิทธิ์แล้ว

⚠️ **ข้อควรระวังสำคัญ**: เครื่องมือนี้รองรับเฉพาะ 'ข้อมูลที่เปิดเผยต่อสาธารณะเท่านั้น' ไม่สามารถวิเคราะห์เนื้อหาที่ต้องล็อกอิน/เสียค่าใช้จ่าย/ตั้งค่าเป็นส่วนตัวได้

## ✨ ฟีเจอร์หลัก

- 🔗 **ระบบตรวจจับลิงก์อัตโนมัติ**: รองรับรูปแบบลิงก์มาตรฐาน/ลิงก์ย่อ/ลิงก์มือถือจากหน้าเพจสาธารณะของ Pinterest
- 🎬 **รองรับหลายรูปแบบไฟล์**: ดึงข้อมูลทรัพยากรวิดีโอ MP4, ภาพเคลื่อนไหว WebM, ภาพนิ่ง JPG/PNG เป็นต้น
- 📐 **แสดงข้อมูลความละเอียด**: แสดงรายการความละเอียดและรูปแบบไฟล์ที่ใช้งานได้ ให้ผู้ใช้เลือกตามความต้องการ
- 📱 **ดีไซน์รองรับทุกอุปกรณ์**: ประสบการณ์การใช้งานที่ลื่นไหลบน ПК / แท็บเล็ต / สมาร์ทโฟน
- ⚡ **สถาปัตยกรรมเน้นฝั่งไคลเอนต์**: ประมวลผลหลักบนเบราว์เซอร์ ลดภาระเซิร์ฟเวอร์และตอบสนองได้รวดเร็ว
- 🔐 **ออกแบบโดยคำนึงถึงความเป็นส่วนตัว**: ไม่บันทึกลิงก์ที่ผู้ใช้ส่ง / ไม่เก็บผลลัพธ์การวิเคราะห์ / ไม่รวบรวมข้อมูลส่วนบุคคลใดๆ

## 🚀 คู่มือการใช้งานด่วน

1. เปิดแอปหรือเว็บไซต์ Pinterest แล้วค้นหา **เนื้อหาสาธารณะ** ที่ต้องการอ้างอิง
2. คัดลอก URL ของหน้าเพจนั้น (ตัวอย่าง: `https://www.pinterest.com/pin/1234567890/`)
3. วางลิงก์ในช่องป้อนข้อมูลของเครื่องมือนี้ แล้วคลิกปุ่ม "วิเคราะห์"
4. ระบบจะดึงข้อมูลเมตาสาธารณะและแสดงรายการทรัพยากรที่ใช้งานได้
5. เลือกรูปแบบ/ความละเอียดที่ต้องการ แล้วคลิกขวา → "บันทึกเป็น" เพื่อบันทึกไปยังอุปกรณ์ของคุณ

> 💡 เคล็ดลับการใช้งาน:
> - โปรดตรวจสอบให้แน่ใจว่าเนื้อหาเป้าหมายตั้งค่าเป็น "สาธารณะ"
> - หากการวิเคราะห์ล้มเหลว ลองรีเฟรชหน้าหรือตรวจสอบการเชื่อมต่อเครือข่าย
> - สำหรับผู้สนใจเรียนรู้เทคนิค แนะนำให้ใช้ Developer Tools ของเบราว์เซอร์ (F12 → Network → Fetch/XHR) ร่วมด้วย

## ⚠️ ข้อกำหนดการใช้งานและข้อจำกัดความรับผิดชอบ (โปรดอ่านอย่างละเอียด)

โปรเจกต์นี้ยึดถือหลักการ "ความเป็นกลางทางเทคนิค" และ "การปฏิบัติตามกฎหมาย" เป็นพื้นฐาน กรุณาทำความเข้าใจข้อต่อไปนี้ก่อนใช้งาน:

### ✅ พฤติกรรมที่แนะนำ
- วิเคราะห์เฉพาะ **เนื้อหาสาธารณะ** ที่คุณมีสิทธิ์เข้าถึงเท่านั้น
- ใช้ทรัพยากรที่ดึงมาเพื่อ **การเรียนรู้ส่วนตัว / การวิจัย / การใช้ประโยชน์ส่วนตัว** เท่านั้น
- หากต้องการเผยแพร่ต่อ / สร้างงานดัดแปลง / ใช้เชิงพาณิชย์ ต้องขออนุญาตจากเจ้าของลิขสิทธิ์ล่วงหน้า
- ระบุแหล่งที่มาและชื่อผู้สร้างสรรค์ผลงานในชิ้นงานของคุณ เคารพสิทธิ์ของครีเอเตอร์

### ❌ พฤติกรรมที่ต้องห้าม
- พยายามวิเคราะห์เนื้อหาที่ต้องล็อกอิน / เสียค่าใช้จ่าย / ตั้งค่าเป็นส่วนตัว
- ใช้เครื่องมือเพื่อวัตถุประสงค์ในการสคราปเชิงพาณิชย์ / บริการรวบรวมข้อมูล / สร้างรายได้จากโฆษณา
- ส่งคำขอจำนวนมากในเวลาสั้นๆ / ใช้เครื่องมืออัตโนมัติ / โจมตีสร้างภาระให้แพลตฟอร์ม
- ดัดแปลง / ลบ / ปิดบังวอเตอร์มาร์ก / ข้อมูลลิขสิทธิ์ / เมตาดาตาของทรัพยากร

> 📜 หลักการทางกฎหมาย:
> การใช้งานเครื่องมือนี้ต้องเป็นไปตาม "พระราชบัญญัติลิขสิทธิ์" "พระราชบัญญัติว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์" ของประเทศไทย รวมถึง "Community Guidelines" และ "Developer Policy" ของ Pinterest
> ผู้พัฒนาขอไม่รับผิดชอบใดๆ ต่อความเสียหายหรือความรับผิดทางกฎหมายที่เกิดจากการใช้งานที่ไม่เหมาะสมโดยผู้ใช้

## 🛠 ข้อมูลทางเทคนิคสำหรับผู้พัฒนา (อ้างอิง)

> ผู้ใช้ทั่วไปสามารถข้ามส่วนนี้ได้

### ภาพรวมสถาปัตยกรรม
```
เบราว์เซอร์ผู้ใช้ → โมดูลวิเคราะห์ฝั่งไคลเอนต์ → Pinterest Public API / OEmbed → การแยกวิเคราะห์ข้อมูลโครงสร้าง → แสดงผลลัพธ์
```

### จุดเด่นทางเทคนิค
- ใช้ `fetch` API ร่วมกับการตั้งค่า CORS Proxy ที่เหมาะสม เพื่อดึงเมตาดาตาจากหน้าเพจสาธารณะ
- แยกวิเคราะห์ข้อมูลโครงสร้าง Schema.org จาก `<script type="application/ld+json">`
- ใช้ Open Graph Tags (`og:video` / `og:image` / `og:title` ฯลฯ) เพื่อเสริมข้อมูลทรัพยากร
- ใช้การตรวจสอบสองชั้นด้วย Regular Expression + DOM Parsing เพื่อเพิ่มความเสถียรของการตรวจจับลิงก์

### คู่มือการติดตั้งบนเซิร์ฟเวอร์ส่วนตัว (อ้างอิง)
```bash
# 1. โคลนรีพอซิทอรี (ตัวอย่าง)
git clone https://github.com/yourname/pinterest-downloader-th.git

# 2. โฮสต์ไฟล์สแตติก (แนะนำใช้ HTTPS)
#    - Vercel / Netlify / Cloudflare Pages (แนะนำสำหรับเริ่มต้น)
#    - Nginx + ใบรับรอง Let's Encrypt (สำหรับเซิร์ฟเวอร์ส่วนตัว)

# 3. ตัวอย่างการตั้งค่า Security Headers (Nginx)
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline';";
add_header X-Content-Type-Options "nosniff";
add_header Referrer-Policy "strict-origin-when-cross-origin";
```

> 🔐 ข้อควรระวังสำหรับการใช้งานจริง:
> - ต้องเปิดใช้งาน HTTPS เพื่อป้องกันการโจมตีแบบ Man-in-the-Middle
> - แนะนำให้ตั้งค่า Rate Limiting เพื่อจำกัดคำขอที่มากเกินไป
> - ควรระมัดระวังในการเปิดเผยลอจิกการวิเคราะห์มากเกินไป เพื่อลดความเสี่ยงในการถูกนำไปใช้ในทางที่ผิด

## ❓ คำถามที่พบบ่อย (FAQ)

**Q: ขึ้นข้อความ "ไม่สามารถดึงเนื้อหาได้" เกิดจากอะไร?**  
A: สาเหตุที่เป็นไปได้: ① ลิงก์ปลายทางเป็นเนื้อหาส่วนตัว / ถูกลบแล้ว ② Pinterest ปรับเปลี่ยนโครงสร้างหน้าเพจชั่วคราว ③ ข้อจำกัดเครือข่าย / ปัญหา CORS วิธีแก้ไข: ตรวจสอบการตั้งค่าสาธารณะ → ลองใช้เครือข่ายอื่น → รอสักครู่แล้วลองใหม่

**Q: วิดีโอที่ดึงมามีน้ำเครื่องหมายการค้า (วอเตอร์มาร์ก) ปกติไหม?**  
A: เครื่องมือนี้ส่งคืนลิงก์ทรัพยากรต้นฉบับที่ Pinterest ให้บริการอย่างเป็นทางการเท่านั้น การมีหรือไม่มีวอเตอร์มาร์กขึ้นอยู่กับตั้งค่าตอนอัปโหลดของผู้สร้างเนื้อหา เครื่องมือนี้ไม่มีการเพิ่ม / ลบ / ดัดแปลงใดๆ ทั้งสิ้น

**Q: รองรับของการวิเคราะห์อัลบั้มหรือบอร์ดแบบกลุ่มไหม?**  
A: เวอร์ชันปัจจุบันมุ่งเน้นการวิเคราะห์พินเดี่ยว เพื่อให้ความสำคัญกับความเสถียรและการปฏิบัติตามกฎระเบียบ สำหรับคำขอการประมวลผลแบบกลุ่ม กรุณาตรวจสอบความสอดคล้องกับ "Developer Policy" ของ Pinterest ด้วยตนเองก่อน

**Q: เครื่องมือนี้เก็บประวัติการใช้งานหรือข้อมูลส่วนบุคคลไหม?**  
A: ไม่เก็บครับ โปรเจกต์นี้เป็นหน้าเว็บสแตติกฝั่งไคลเอนต์ล้วน ไม่มีส่วนของแบ็กเอนด์บันทึก 로그 / สคริปต์วิเคราะห์ / หรือระบบติดตามผ่านคุกกี้ใดๆ การประมวลผลทั้งหมดเกิดขึ้นภายในเบราว์เซอร์ของคุณเท่านั้น
